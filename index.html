HiPPO & S4 Kernel Engine

Explore the mathematical foundations of structured state spaces. The HiPPO (High-Order Polynomial Projection Operator) framework provides structured initialization for the A matrix that enables long-range memory. Visualize how different HiPPO variants produce different convolutional kernels and how discretization methods affect the resulting discrete-time system.

HiPPO Matrix Visualization

LegS (Scaled Legendre Measure): Projects input history onto Legendre polynomials with exponentially-decaying measure. Produces a lower-triangular A matrix. Key insight: simply changing A from random to HiPPO improved sequential MNIST from 60% → 98%.

Eigenspectrum Analysis

Why eigenvalues matter: The eigenvalues of A determine the system's long-range memory. HiPPO matrices have eigenvalues clustered along the left half of the complex plane, enabling stable long-range dependencies. Random matrices have scattered eigenvalues leading to rapid information decay.

Selective Scan Simulator

Mamba's key innovation: making SSM parameters (Δ, B, C) input-dependent. Unlike S4's fixed dynamics, the selective scan allows the model to dynamically decide what to remember and what to forget based on the input sequence. This is what gives Mamba its content-aware reasoning ability.

Input Sequence & Selective Parameters

Fixed SSM (S4-style)

Fixed dynamics: Δ, B, C are learned but constant across the sequence. The model cannot distinguish relevant from irrelevant tokens — it treats everything equally, leading to information overflow on long sequences.

Selective SSM (Mamba-style)

Selective dynamics: Δ(x), B(x), C(x) are computed from the input. Large Δ → "remember this" (strong update). Small Δ → "skip this" (near-identity transition). The model learns to gate information flow based on content.

Parameter Dynamics Visualization

Selective SSM: Δ_t = softplus(Linear_Δ(x_t)),   B_t = Linear_B(x_t),   C_t = Linear_C(x_t)   →   Ā_t = exp(ΔA),   B̄_t = (ΔA)^{-1}(exp(ΔA) - I)·ΔB

SSM Evolution Timeline

Trace the evolution of State Space Models from the theoretical foundations of HiPPO (2020) through S4, Mamba, and the latest Mamba-3 (ICLR 2026). Each generation introduced key innovations that pushed the Pareto frontier of quality vs. efficiency.

Architecture Timeline

2020

HiPPO

High-Order Polynomial Projection Operators. Foundation: structured A matrix initialization for long-range memory.

2021

LSSL

Linear State Space Layer. First deep SSM, but computationally expensive — O(N²L) per layer.

2022

S4

Structured State Spaces for Sequence Modeling. Diagonal + Low-Rank (DPLR) parameterization enables O(NL log L) via FFT.

2022

S4D / S5

Diagonal SSMs. Showed diagonal A matrices suffice, simplifying from DPLR. S5 adds parallel scan.

2023

H3 / Hyena

Hungry Hungry Hippos. Two stacked SSMs with multiplicative gating. Hyena replaces attention with long convolutions.

2023

Mamba

Selective State Spaces. Input-dependent Δ, B, C. Hardware-aware parallel scan. First SSM to match Transformers at scale.

2024

Mamba-2

State Space Duality (SSD). Reveals SSMs ≡ structured (semiseparable) matrices ≡ certain linear attention variants. 2-8× faster.

2026

Mamba-3

Complex-valued states, MIMO formulation, exponential-trapezoidal discretization. New Pareto frontier at ICLR 2026.
